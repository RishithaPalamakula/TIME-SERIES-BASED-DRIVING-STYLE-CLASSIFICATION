# TIME-SERIES-BASED-DRIVING-STYLE-CLASSIFICATION

## Project Overview
This project analyzes driving behavior using time series data and classifies the driving style using machine learning. Parameters like acceleration, braking, and speed patterns are considered.

## Dataset
- **dataset.csv**: Driving data used for analysis

## Application
- **app.py**: Main Python application file for classification
